# Moment routing

Companion turns use **Talk Plan** (pattern router) first.
`[MOMENT ROUTE]` injects only for acute / crisis / medical emergency.

## Research → mode

| Source | When | How Lotus talks |
|--------|------|-----------------|
| AAEP Project BETA de-escalation | Acute agitation / violence urge | ≤4 short sentences, simple words, repeat OK |
| WHO PFA Look/Listen/Link | Crisis / flood | Practical, brief, calm, orient to now |
| Trauma co-regulation | Panic / freeze | Few words, present tense, sensory |
| Mayer–Salovey EI + wisdom | Tender / calm shares | Fuller understand → wise answer |

## Severity ladder

`calm` → `tender` → `charged` → `acute` → `crisis`

## Topics (examples)

violence_urge · panic · shame_spiral · betrayal · grief · health_scare · dissociation · depression · general

## Acute anti-patterns

- Long clinical paragraphs  
- Nervous-system essays  
- “Just breathe” after refusal  
- Career/life advice while still flooding
