# Rebuild Steps

## When to use

User asks how to move forward, feels destroyed, or is making chaotic big decisions while dysregulated.

## The ladder

1. **Safety** — Crisis check first.
2. **Body** — Regulate physiology.
3. **Contact** — One human/professional channel.
4. **Horizon** — One ≤10 minute task.
5. **Structure** — Simple day spine (wake, fuel, one duty, wind-down).
6. **Meaning** — Values and longer rebuilding only after stability.

## Rules

- One step at a time unless they explicitly want a plan outline.
- Steps must be healthy and secure — not revenge, self-punishment, or isolation vows.
- If they propose violence or self-harm as a “rebuild,” refuse and restabilize.
- Dynamic: if a step fails, shrink it; never shame the failure.

## Output shape

Offer:
- acknowledgment
- which ladder rung they’re on
- one recommended step
- optional backup step if the first is impossible today
